# Mar Rojo - Base super secreta

- Ubicación: Mar Rojo, cerca de la costa de Arabia Saudita
- Propósito: Base de operaciones de la Legión para misiones en Oriente Medio y África del Norte
- Instalaciones: Hangar para vehículos anfibios, laboratorio de investigación, dormitorios para 20 personas, centro de comunicaciones
- Seguridad: Patrullas regulares de drones y sensores submarinos para detectar intrusos
